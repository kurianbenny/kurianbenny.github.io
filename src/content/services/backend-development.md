## The application behind the interface

I work across PHP, Python, and Ruby frameworks to develop backend applications, APIs, and integrations. The choice of framework follows the requirements and the systems already in place.

## Frameworks and platforms

- **PHP:** Laravel, Symfony, CodeIgniter, Yii, and CakePHP.
- **Python:** Django Ninja and FastAPI.
- **Ruby:** Ruby on Rails.
- **CMS:** WordPress and Drupal, including application and integration requirements around those platforms.
- **Databases:** MySQL and NoSQL, with the data model chosen around the application’s needs.

## How I can help

- Develop backend features and application workflows.
- Build and integrate APIs.
- Extend existing framework-based applications.
- Connect frontend behavior with business logic.
- Work through integrations between applications and business systems.

## Where we start

Share the current stack, the relevant workflow, and the outcome you need. For an existing application, the framework and version help define the scope of the change.
