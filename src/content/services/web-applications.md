## From the interface to the application

I bring experience across React and Next.js, PHP frameworks such as Laravel and Symfony, Python frameworks including Django Ninja and FastAPI, and Ruby on Rails. That breadth helps me work across application boundaries and choose an approach that fits the problem.

## How I can help

- Develop web interfaces and application workflows.
- Build and integrate backend APIs.
- Extend an existing application or develop a new one.
- Connect frontend behavior with backend business logic.

## Where we start

A conversation about your users, existing systems, and the outcome you need. From there, we can define the scope and the right technical approach.

## Useful project starting points

A new application with a defined user journey, a feature added to an existing product, or an integration between systems. The requirements and current codebase determine the implementation approach.

## What to share before we begin

Tell me who will use the application, the workflow it needs to support, and any technology or integration constraints. If there is an existing system, a walkthrough and access to its documentation help make the scope concrete.
