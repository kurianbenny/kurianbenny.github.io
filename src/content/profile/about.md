## A developer with a view of the whole application

I’m Kurian Benny, a full-stack developer with twelve years of experience across web applications, backend APIs, content platforms, business systems, and DevOps. I work across the application and the infrastructure that supports it.

That background gives me a useful perspective when a project needs more than one part of the stack. A frontend decision can affect an API. A business workflow can shape a data model. A deployment choice can influence how a team works with the software later.

## Where my experience fits

My development background spans several ecosystems:

- **JavaScript:** React and Next.js for web interfaces and applications.
- **PHP:** Laravel, Symfony, CodeIgniter, Yii, and CakePHP for backend applications and integrations.
- **CMS platforms:** WordPress and Drupal for content-driven websites.
- **Python:** Django Ninja and FastAPI for backend APIs and services.
- **Ruby:** Ruby on Rails for web application development.
- **Business software:** ERPNext and Odoo customization, along with the workflows and integrations around them.
- **Databases & analytics:** MySQL and NoSQL for application data, and Metabase for business intelligence and data dashboards.

## Cloud infrastructure and DevOps

My DevOps work includes AWS, DigitalOcean, VPS hosting, server management, and deployment. I can help connect development choices with the practical requirements of hosting, environment configuration, releases, and running the application.

That means a project conversation can cover both what needs to be built and how it will be deployed and maintained.

These technologies serve different purposes. The starting point for a project is understanding its needs and the systems already in place, then choosing a suitable approach.

## The work I can help with

My services cover full-stack web application development, backend APIs across PHP, Python, and Ruby, CMS websites, ERPNext and Odoo customization, Metabase data analytics, cloud hosting, and DevOps. I also offer technical website reviews, including SEO foundations and the practical questions that come with launching an AI-assisted website.

Sometimes the useful next step is a new feature. Sometimes it is improving an existing application or making the path to production easier to understand. The scope should follow the problem.

## How I approach a project

I start with the users, the business workflow, and the outcome the project needs to achieve. From there, we can clarify the constraints, define a practical scope, and decide what to build or improve first.

Clear communication matters throughout that work. The implementation should be understandable to the people who will use it, update it, and look after it after launch.
